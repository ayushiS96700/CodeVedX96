# 🤖 AI Chatbot for Internal Helpdesk

An AI-powered chatbot developed using **Python** and **Flask** to provide instant responses to frequently asked questions within an organization. The chatbot uses NLP concepts and intent-based matching to answer user queries and allows easy updates to the FAQ dataset.

## 📌 Features

- 💬 Question-Answer Chatbot
- 🧠 Intent-Based Response System
- 📚 FAQ Dataset Training
- 🔄 Admin Update Capability
- 🌐 Flask Web Interface
- ⚡ Fast and User-Friendly

## 🛠️ Technologies Used

- Python 3.x
- Flask
- HTML5
- CSS3
- JavaScript
- JSON
- NLP (Basic Intent Recognition)

## 🚀 Installation

### Clone the Repository

bash
git clone https://github.com/your-username/CODEVEDX96.git


### Navigate to Project Folder

bash
cd CODEVEDX96/AI-Chatbot-Internal-Helpdesk


### Install Dependencies

bash
pip install -r requirements.txt


### Run the Application

bash
python app.py


Open your browser and visit:
http://127.0.0.1:5000/
